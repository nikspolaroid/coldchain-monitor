# Cold Chain Monitoring & Predictive Maintenance

Industrial IoT simulation: 3 cold storage units with real-time compliance
monitoring (temperature, humidity, door status) and vibration-based
predictive maintenance for refrigeration compressors.

## Stack
- Docker (OrbStack)
- Mosquitto (MQTT broker)
- Node-RED (data flow / processing)
- InfluxDB (time-series database)
- Grafana (dashboards)
